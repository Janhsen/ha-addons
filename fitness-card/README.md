# Fitness card

Home Assistant custom card `custom:fitness-card` (day, week and long-term values, tours and LiveTrack from Garmin sensors in the recorder).
Load it as a dashboard resource (type module) from jsDelivr with a fixed commit:

    https://cdn.jsdelivr.net/gh/Janhsen/ha-addons@<commit>/fitness-card/fitness-card.js

Names, sensor prefixes and the person mapping come from the card configuration (`users`, `names`, `entities`, `person_match`, keys `p1`/`p2`).
